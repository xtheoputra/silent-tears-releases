# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.9.0 (latest release) | Yes |
| Older builds | No |

Only the latest release receives fixes. There are no backports.

## Reporting a vulnerability

Please report privately by email to **mail.harastaputra@gmail.com**, not as a public issue. Include:

- the Silent Tears version and Windows version;
- whether the application was running as Administrator;
- the minimal steps to reproduce, and what an attacker gains.

Do not attach the application's `logs/`, `snapshots/` or `config.json` folders and files: they contain personal data about your PC. Extract only the relevant lines and redact addresses that identify you.

A problem with a downloaded file itself (a SHA-256 that does not match the value in the README or the release notes) is also a security report.
